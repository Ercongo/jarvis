Política de privacidad

Jarvis / Athena · asistente personal de código abierto · actualizada el 10 de noviembre de 2026

Jarvis (también llamado Athena) es un asistente de voz de uso personal que funciona en el ordenador de su propietario. No es un servicio público: no tiene usuarios externos, no vende nada y no comparte datos con terceros con fines comerciales. El código es abierto y está en github.com/Ercongo/jarvis.

Qué datos usa

  • Cuentas de Google (Calendar, Gmail, YouTube): solo las del propietario, con su permiso expreso, para leer y crear eventos de su calendario, leer y enviar sus correos y subir vídeos a su propio canal de YouTube.
  • Redes sociales (Instagram, Facebook, TikTok, Pinterest): solo las cuentas del propietario o de su personaje digital, para publicar el contenido que él aprueba y leer las estadísticas y comentarios de esas publicaciones.
  • Voz y texto de las órdenes que se le dan al asistente, para entenderlas y contestar.

Dónde se guardan

Los permisos y los datos se guardan únicamente en el ordenador del propietario. Las órdenes pueden procesarse con servicios de inteligencia artificial (por ejemplo, Groq) solo para generar la respuesta. No se crean copias en servidores propios ni se ceden a nadie.

Servicios de API de YouTube

Jarvis usa los Servicios de API de YouTube (YouTube Data API v3) para subir vídeos al canal de YouTube del propietario, poner su título, descripción y etiquetas, y leer y responder los comentarios de ese canal. Al usar estas funciones se aceptan las Condiciones del Servicio de YouTube, y los datos se tratan también según la Política de Privacidad de Google (www.google.com/policies/privacy).

Datos de YouTube que se usan: el identificador y el nombre del canal, los vídeos que el propio asistente sube y los comentarios de esos vídeos. No se guardan datos de otros usuarios de YouTube salvo el texto del comentario mientras se responde, y no se comparten con nadie.

Uso de datos de Google

El uso de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. Los datos de Google no se usan para publicidad, no se venden y no se usan para entrenar modelos de inteligencia artificial.

Contenido generado con IA

Las imágenes, vídeos, canciones y textos del personaje digital Asuka se crean con inteligencia artificial y se publican identificados como tales.

Cómo retirar el permiso o borrar los datos

El propietario puede retirar el acceso en cualquier momento desde la página de seguridad de su cuenta de Google, security.google.com/settings/security/permissions (también en myaccount.google.com/permissions), o desde los ajustes de cada red social.

Borrado de datos: los permisos y datos guardados se eliminan al retirar el acceso o al borrar la carpeta del asistente en su ordenador. Los datos de la API de YouTube que se guardan en el ordenador (por ejemplo, la lista de vídeos subidos y comentarios pendientes) se actualizan o se borran como máximo a los 30 días. Para pedir el borrado de cualquier dato, escribe en la página de contacto indicada abajo y se hará en un plazo máximo de 7 días.

English summary. Jarvis/Athena is a personal, open-source voice assistant used only by its owner on his own computer. It accesses only the owner's Google (Calendar, Gmail, YouTube) and social media accounts, with explicit consent, to manage his calendar and email and to publish content he approves. Data stays on the owner's computer, is never sold or shared, is not used for advertising or to train AI models, and Google user data is handled according to the Google API Services User Data Policy, including the Limited Use requirements. It uses the YouTube API Services; by using them you agree to the YouTube Terms of Service (https://www.youtube.com/t/terms), and the Google Privacy Policy (http://www.google.com/policies/privacy) applies. Access can be revoked at any time at https://security.google.com/settings/security/permissions; stored YouTube API data is refreshed or deleted within 30 days. Contact: github.com/Ercongo/jarvis/issues.
